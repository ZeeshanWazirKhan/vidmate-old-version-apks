# VidMate Old Version APK Archive

This is an independent archive of selected older VidMate APK files. It is not an official VidMate repository and is not operated or endorsed by the app's developer.

The APK files are distributed as GitHub Release assets rather than being committed to the repository. Use the release page to choose an exact version, and compare the downloaded file with `SHA256SUMS.txt` before installation.

- [Open the APK release](https://github.com/ZeeshanWazirKhan/vidmate-old-version-apks/releases/tag/archive-v1)
- `download-urls.csv` maps every published version to its direct release-asset URL.

## Archive scope

- 24 selected APK files are included in the release.
- Each published filename identifies one exact version.
- The alternate VidMate 3.15 file is not published, preventing one version label from pointing to two different files.
- VidMate 3.19 is not published because its local review remains unresolved.

## Important limitations

A matching checksum confirms that a downloaded file is byte-for-byte identical to the archived file. It does not prove that an APK is safe, compatible with a particular phone, or able to connect to services that may have changed since the version was released.

Installing an older APK may require removing a newer installation, which can delete private app data. Review Android security warnings and requested permissions before continuing.
