# VidMate old-version APK archive

This release contains 24 selected historical VidMate APK files used by the independent VidMate Old Version project.

- APKs are release assets and are not stored in Git history.
- SHA-256 values are available in `SHA256SUMS.txt` in the repository.
- The alternate 3.15 artifact and review-required 3.19 artifact are excluded.
- A matching hash establishes file identity only; it is not a safety or compatibility guarantee.
